## Why PDF Files Become Unnecessarily Large

PDF files often balloon in size due to several common factors:
- **Uncompressed High-Res Scans**: Standard document scanners often embed uncompressed 300+ DPI bitmap images.
- **Embedded Font Families**: Unused vector font subsets included inside the document stream.
- **Duplicate Object Streams**: Redundant graphics state declarations and uncompressed metadata metadata trees.

By optimizing bitmap streams and removing redundant metadata without re-encoding text, you achieve up to **80% file size reduction** while keeping printed text laser-sharp.
